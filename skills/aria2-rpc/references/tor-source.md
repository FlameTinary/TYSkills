# 搜索源契约（a2 find 的「源」由你自己配置）

a2 **不内置任何种子站/索引站**。`a2 find` 只是把关键词交给一条你自己配置的命令，再把结果
过滤、排序、缓存，`a2 grab` 负责元数据校验与入库。换站点 = 换一行配置，不用改脚本。

## 1. 配置

配置写在 **`~/.aria2/a2.conf`**（不是 aria2.conf —— aria2 不认识的键会打 `Unknown option` 警告）：

```ini
tor-source-cmd=python3 ~/.aria2/tor-source-demo.py
tor-source-timeout=60
tor-source-cache-ttl=900
```

临时换源用环境变量（优先级更高）：`A2_TOR_CMD='…' a2 find 关键词`。
`install-a2.sh` 已经把模板装到 `~/.aria2/a2.conf`，并且把两个示例源脚本放进 `~/.aria2/`：

| 文件 | 用途 |
|---|---|
| `~/.aria2/tor-source-demo.py` | **离线自测源**：不联网，读到关键词后返回内置示例行。用来验证 find/grab 整条流程 |
| `~/.aria2/tor-source-template.py` | **接入骨架**：填站点 URL 与解析函数即可 |

命令的调用约定（三种传参方式同时可用，挑一种即可）：

- 占位符：`tor-source-cmd=mysearch.py --q {query} --p {page}`
  - `{query}` = URL 编码后的关键词（shell 安全，直接拼在命令里没问题）
  - `{page}` = 页码，从 1 开始
- 不写占位符：关键词会作为**最后一个参数**追加到命令末尾
- 环境变量：`A2_QUERY`（原始关键词）、`A2_PAGE`（页码）、`A2_PAGES`（本次总共请求几页）

a2 每页只调用一次源命令（默认 1 页，`a2 find … --pages 3` 时依次调用 3 次），
**限流/重试/遵守站点规则由源自己负责**。

## 2. 输出契约（唯一硬性要求）

源命令把结果以 **JSON 打到 stdout**：数组，或 `{"rows": [...]}`（也认 `results` / `data`）。

- stdout **只允许**出现 JSON；日志、进度、警告全部走 stderr
- 失败就**非零退出**（a2 会把退出码与 stderr 末尾原样报给用户）
- 单行只要「标题 + 磁力或 infohash」两样就能用，其余字段缺失都不致命

| 字段 | 必需 | 说明 / 别名 |
|---|---|---|
| `title` | ✅ | 种子名称（别名 `name`）。缺失的行会被丢弃并在统计里体现 |
| `magnet` | 二选一 | 完整磁力，别名 `magnet_uri` / `magnet_link` |
| `info_hash` | 二选一 | 32/40 位 hex，别名 `infohash` / `ih` / `hash`。a2 会拼成 `magnet:?xt=urn:btih:…`，可选带 `trackers` |
| `size_bytes` | 可选 | 字节数（别名 `bytes`/`length`）；也可用 `size`（数字=字节，字符串=`"3.5 GB"`）或 `size_gb` |
| `seeders` / `leechers` | 可选 | 别名 `seeds`/`s`、`leech`/`l`；缺失按 0 处理（`--min-seeds` 会因此过滤掉它们） |
| `category` | 可选 | 别名 `cat`。写 `Movies`/`TV` 时 a2 直接用；留空则**按标题猜**（整季/年份/分辨率等正则） |
| `url` | 可选 | 详情页地址（别名 `detail`/`link`/`page`）；`a2 grab <片段>` 会匹配它 |
| `source` | 可选 | 源名（别名 `src`/`site`/`indexer`），只用于显示 |

一行最小示例：

```json
[{"title": "Some.Show.S01.1080p.WEB-DL", "info_hash": "0123456789abcdef0123456789abcdef01234567",
  "size_bytes": 25769803776, "seeders": 18, "category": "TV"}]
```

如果源返回了行但**一行都用不了**（缺 title，或既没有 magnet 也没有 info_hash），a2 会明确说
"源返回了 N 行，但没有一行能用"，而不是含糊地报"没有结果"。

## 3. 写自己的源

照 `tor-source-template.py` 填三处：`SEARCH_URL` / `REQUEST_HEADERS`（UA、Cookie）、`parse()`
（把响应变成 rows）。要点：

- **别把站点规则写进 a2**：过滤（整季/单集/噪音词）、排序、缓存都由 a2 统一做，源只管"如实返回站点给了什么"
- **返回原始行，不要自己筛**：a2 的缓存存的是源返回的原始行，`--all` / `--res` / `--min-seeds` 在读取之后才应用
- **站点写 0 条要当错误报**：如果站点结构变了/被 WAF 拦，源应该非零退出并说明，而不是打一个空数组 ——
  空数组在 a2 那边看起来就是"确实没有这个资源"
- **搜索语言跟着站点走**：很多站点只认真英文关键词，中文查询会返回无关结果（这属于源的调优问题）
- 需要 Cookie/登录态：放进 `REQUEST_HEADERS`，别把凭据写进命令行参数（会出现在 `ps` 里）；
  配置里确实要放 token 时，`chmod 600 ~/.aria2/a2.conf`，并知道 a2 打印命令时会自动打码

## 4. 结果怎么被使用

```bash
a2 find 关键词                      # 默认过滤：电影全留、剧集要「整季/全集」且不是单集、噪音词剔除
a2 find 关键词 --all                # 放宽到全部分类（含单集；噪音词仍剔除）
a2 find 关键词 --pages 3            # 让源多给几页（源不分页时会在没有新内容的那页自动停）
a2 find 关键词 --json               # 直接看规范化后的行（调试源时最好用）
a2 grab 2                           # 取第 2 条：先 bt-metadata-only 校验真做种，通过才入库
a2 grab 2 --no-verify               # 跳过校验直接入库
```

- 结果缓存在 `~/.aria2/find-cache.json`（v4：按 **源指纹 + 关键词 + 页数** 分键，默认 15 分钟）。
  缓存里**不写源命令原文**（可能带 token），只写指纹与打码后的标签；`--refresh` 强制重抓
- `a2 grab <序号>` 按「你屏幕上看到的那份」（过滤+排序后的视图）取，不是站点原始行号；
  缓存被别的查询覆盖后，旧序号会失效（会明确报"序号超出范围"或取到新查询的那条）
- `a2 grab` 分类落库用的是**条目标题**（源的分类/标题推断），所以整季包不会因为磁力里的 `dn=` 被简写而落错库
- `a2 grab <标题片段>` 只在当前缓存视图里找；`a2 grab <infohash|磁力>` 不依赖缓存

## 5. 排查

| 现象 | 原因 / 处理 |
|---|---|
| `没有配置搜索源：a2 不内置任何种子站…` | `~/.aria2/a2.conf` 里 `tor-source-cmd=` 是空的。填上，或临时 `A2_TOR_CMD=… a2 find …` |
| `搜索源失败（exit 3）：…` | 源自己退出了。先单独在终端跑一遍那条命令（`A2_TOR_DEBUG=1` 会让 a2 打印完整命令，注意可能含凭据） |
| `搜索源输出不是 JSON（…）前 200 字节：…` | 源把日志/HTML 打到 stdout 了。日志走 stderr，stdout 只留 JSON |
| `搜索源超时（60s…）` | 源卡住（网络慢/站点无响应）。调 `tor-source-timeout`，或在源里加自己的超时与重试 |
| `搜索源起不来：…` | 命令路径不对、解释器不在 PATH（服务管理器与服务终端 PATH 不同，Windows 计划任务里更是空的）、脚本没有执行权限 |
| `搜索源返回了 N 行，但没有一行能用` | 字段名不在契约里（对照第 2 节表；`--json` 看不到东西就说明规范化阶段就丢了） |
| `源给了 N 条，但没有一条通过默认过滤` | 过滤生效了。`--all` 放宽分类、`--min-seeds 0` 放宽做种数、`--res` 去掉分辨率限制 |
| `源返回 0 条结果` | 关键词在源那边没命中（或源对中文关键词不友好）。换关键词；先单独验证源 |
| 结果看着是上一次的 | 15 分钟内复用缓存。`--refresh` 强制重抓 |
| `序号 N 超出范围 1..M` | 缓存被别的查询覆盖了（或用了 `--pages` 改变了结果集）。重新 `a2 find` 再 grab |
| `缓存里找不到 '…'` | 片段只在**当前视图**里找。换序号，或先 `a2 find` 出这个词 |
