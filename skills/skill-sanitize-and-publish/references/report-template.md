# 脱敏报告模板

交付给用户的处置清单。**每条命中都必须有一行结论**，包括「保留」的理由。
审计器可以直接生成骨架：`python3 scripts/audit_skill.py <目录> --report 脱敏报告.md`，
把生成的表格补上「处置 / 理由 / 落地位置」三列即可。
